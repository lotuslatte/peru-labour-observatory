Cargar desde tu programa

Stata 14 o posterior

shell curl -LO https://lotuslatte.github.io/peru-labour-observatory/data/latest/observatorio_laboral.dta
use observatorio_laboral.dta, clear

R

d <- read.csv("https://lotuslatte.github.io/peru-labour-observatory/data/latest/por_indicador/informality.csv")

Python

import pandas as pd
d = pd.read_csv("https://lotuslatte.github.io/peru-labour-observatory/data/latest/estimates.csv.gz", dtype={"key": str})

Las rutas de /data/latest/ siempre apuntan a la última versión. Para que un resultado sea reproducible, usa los archivos fijos de la versión publicada.

Diccionario y verificación

  • codebook.csv: indicadores, desagregaciones, columnas y notas de método.

  • manifest.json: tamaño y SHA-256 de cada archivo.
  • index.json: índice de los JSON del sitio.

Sellos de calidad

SelloRegla y uso
ARSE menor que 15%. Se publica.
BRSE de 15% a 30%. Se publica; conviene leerla con cautela.
SRSE de 30% o más, o n menor que 30. Se suprime: v queda vacío (null).
